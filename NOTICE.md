# Attribution

The network follows the SPAMO design (dual GCN encoders, neighborhood-constrained cross-modal fusion). The sparse
execution backend comes from the revision experiments of this project.

RNA / ADT / ATAC preprocessing (`src/spamo/preprocess.py`) follows the original SPAMO implementation, which adapts code by
Yahui Long from SpatialGlue (<https://github.com/JinmiaoChenLab/SpatialGlue>, AGPL-3.0). The upstream copyright and licence
